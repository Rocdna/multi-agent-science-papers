# 笔记界面演示

> **这是一份展示排版的示例，不是 AutoDFT 的真实阅读笔记，也不代表该论文已经读完。** 内容可以替换为自己的方法总结、截图和思考。

## 研究问题

写下论文想解决的问题，以及自己为什么关注它。可以先写一两句话，阅读过程中再逐步补充。

## 方法与流程

用自己的语言描述输入、主要步骤、输出与验证方式。不必复述整篇论文，优先记录以后回看时最有用的内容。

![示例流程图：输入、方法、验证三个环节，供笔记排版演示使用](assets/demo-flow.svg)

*图示仅用于演示图片展示，不是论文中的方法图。点击图片可以放大查看。*

| 关注点 | 可以记录的内容 |
|---|---|
| 输入 | 数据、任务和必要条件 |
| 方法 | 主要模块及其关系 |
| 验证 | 对照实验、指标和局限 |

## 我的想法

> **个人思考**：为什么这种设计可能有效？它和自己读过的其他论文有什么联系？哪些结论还需要进一步核对？

这一部分可以自由写。观点不确定时保留问题，比为了填满模板而写下未经确认的结论更有用。

## 实验与局限

- 记录重要图表的页码、编号和实验条件。
- 分开记录作者的结论和自己的判断。
- 对暂时没看懂的部分标记“待核对”。

## 视频与其他附件

正文可以包含短视频。第一版用浏览器原生播放器，点击后播放，不自动播放；当前示例没有实际视频文件。

添加视频时，在 Markdown 中使用 `<video controls preload="none" playsinline src="assets/你的短视频.mp4"></video>`，视频和图片的路径均相对于这份笔记。
