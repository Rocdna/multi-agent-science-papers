# Multi-agent × AI for Materials

持续整理多智能体与 AI 材料研究相关文献，记录论文分类、核心工作、发表信息和代码资源，逐步积累自己的阅读与复现笔记。

目前以材料科学为主要应用场景，同时收录相关通用科研 Agent、综述和评测工作。文献来自个人 Zotero 收藏；收录表示已搜集，不代表已经读完。

**在线阅读：[rocaler.asia](https://rocaler.asia)**

网站汇总多智能体与 AI for Science 相关论文，支持搜索、分类筛选、年份排序和展开论文详情，方便在电脑、平板和手机上查阅。内容随文献收集和阅读持续更新，网站由 Cloudflare 托管。

## 电脑、平板与手机阅读

页面使用 Bootstrap 5.3.8 的响应式筛选抽屉，文献内容沿用现有表格与卡片布局。

- 宽屏（992px 起）：完整表格，直接选择筛选和排序条件。
- 平板及窄屏（768–991px）：文献卡片，信息分为三列；筛选收进抽屉。
- 手机（768px 以下）：单列文献卡片，信息按两列排列；小屏详情改为上下排版。
- 搜索和文献类型保持可见，筛选即时生效，页面显示已选条件；抽屉支持关闭按钮、遮罩和 Escape 键关闭。
- 研究方向下拉框附分类说明：电脑悬浮或用方向键浏览时显示气泡，手机直接在选项下展示；确认选择后才筛选，支持键盘操作。

Bootstrap 文件保存在 `vendor/bootstrap/`，响应式调整位于 `assets/responsive.css`。下载和部署时保留完整目录即可，无需构建命令。

文献目录和独立笔记页右上方用太阳、月亮图标选择浅色或深色主题。没有手动选择时按系统明暗主题显示，并响应系统变化；手动选择后保存在当前浏览器，同一站点的页面与标签页共享设置。界面只提供两种模式，这是显示偏好，不影响仓库中的阅读状态。

## 分页、阅读状态与笔记

文献先按全部数据搜索、筛选和排序，再分页显示；默认在类别内按年份从旧到新，同年按名称排列，重置后也恢复该顺序。默认电脑每页 20 篇、平板 12 篇、手机 10 篇，也可手动调整。打开和关闭笔记不会重置当前分页和筛选。

阅读状态提供“未读、阅读中、已读”，未填写时默认未读。云端接通前，记录由 `data/reading-status.json` 生成并随站点发布；接通后，各设备读取 D1，维护者通过登录后的管理页修改。云端不可用时明确显示静态副本或最近同步记录。

状态标记保留文字，并用灰色空心圆（未读）、琥珀色半圆（阅读中）、绿色对勾（已读）区分，浅色与深色模式均适用。当前 MARS、LLEMA、MADE 已按用户要求标记为阅读中。

每篇文献可以关联多份 Markdown 笔记，卡片只显示一个“笔记 · 数量”入口。默认打开最近更新的笔记；电脑在侧栏切换，手机和平板在顶部选择。笔记用 Bootstrap 弹窗展示，手机为全屏，支持章节目录、图片放大和原生短视频播放器。

首页提供“最近更新”和“笔记全文检索”。检索结果显示命中段落，点击后进入相应章节并高亮关键词；返回时保留目录筛选与检索词。最近更新展示有记录的内容变动，不把论文发表年份当作收录日期。

笔记可记录当前浏览器的阅读位置，下次打开时选择“继续阅读”或“从头开始”。记录仅保存在本机浏览器，可能被清除，不影响站点统一维护的已读状态，也不提供跨设备同步。

“独立打开”进入真正的阅读页 `note.html?id=论文key&note=笔记id`，方便分享和长时间阅读；独立页同样可以切换笔记。此前仅含论文 key 的链接仍可使用，默认打开最近更新的一份。弹窗与独立页共用笔记和渲染逻辑。

真实笔记使用 UTF-8 编码的 `.md` 文件，放在 `notes/` 中，通过 `notes/index.json` 关联论文的稳定 `key`。更新笔记或阅读状态后运行 `python scripts/build_notes.py`，生成可离线使用的笔记与阅读状态数据。文字和随仓库发布的附件属于公开内容；当前没有网页上传或在线保存入口，上传文件到 GitHub 后仍需完成关联和生成步骤。

云端阅读状态管理已准备好，支持管理员登录后逐篇或批量修改；需先按 [Cloudflare Workers 接入说明](docs/CLOUDFLARE_SETUP.md) 配置 D1 与管理员密码并部署。接通前仍使用静态记录，笔记编辑保持原有维护方式。

## 文献画布

从目录右上角的“文献导图”进入 [公开画布](mindmap.html)。顶部使用紧凑图标工具栏，画布占据窗口主体；支持五色分类、分支折叠、画布移动缩放、元素定位、适合窗口和图片放大。初始导图沿用当前 34 篇文献及已有评级，配图由维护者添加。

点击“打开导图文件”或把文件拖进画布，可直接查看 `.xmind` 文件（XMind 8 及更新版本）或 JSON。JSON 支持本页导出格式、Mind Elixir 数据和 XMind `content.json`，兼容 UTF-8 BOM／UTF-16 编码。上传内容只在当前浏览中显示，刷新页面即恢复公开版，不写入网站或浏览器存储。

维护公开导图时，替换 `mindmaps/library.json`，运行 `python scripts/build_mindmap.py`，将源文件与生成的 `assets/mindmap-data.js` 随网站发布。编辑功能代码仍保留在 `?edit=1` 中供内部维护使用，页面默认不显示入口。

使用本地 MIT 开源库 Mind Elixir 5.15.1，无需后端或运行时 CDN。[功能模式分析](docs/MINDMAP_UX.md) 记录 Xmind 参考依据和取舍；[维护说明](CONTRIBUTING.md#维护文献导图) 记录保存与发布步骤。

## 内容与维护原则

- 保留论文原始链接和作者资源链接，便于回到原文核对。
- 区分正式发表版本与预印本，区分作者实现与第三方复现。
- 论文报告的结果与个人阅读判断分别记录；实验指标保留对应任务和条件。
- 会议等级、期刊分区和代码状态保留核验口径与来源，随信息变化修订。
- 新增或修改论文时同步维护 Markdown 汇总与 HTML 展示。当前两份文件尚未建立自动同步流程。

原有文献沿用已记录的核验信息；2026-11-03 单独核验并新增 LAMMPS-Agents、Rep-CodeGen、GoT-Nano 和 MACS，未重新核验全部论文及评级。具体来源和说明见汇总文件与展示页。
