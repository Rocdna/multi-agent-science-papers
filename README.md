# Multi-agent × AI for Materials

持续整理多智能体与 AI 材料研究相关文献，记录论文分类、核心工作、发表信息和代码资源，逐步积累自己的阅读与复现笔记。

目前以材料科学为主要应用场景，同时收录相关通用科研 Agent、综述和评测工作。文献来自个人 Zotero 收藏；收录表示已搜集，不代表已经读完。

**在线阅读：[rocaler.asia](https://rocaler.asia)**

网站汇总多智能体与 AI for Science 相关论文，支持搜索、分类筛选、年份排序和展开论文详情，方便在电脑、平板和手机上查阅。内容随文献收集和阅读持续更新，网站由 Cloudflare 托管。

## 从这里开始

- [在线文献网站](https://rocaler.asia)：直接打开交互页面，无需下载仓库。
- [文献分类汇总](Multi-agent_AI材料文献总结.md)：直接在 GitHub 阅读。
- [本地展示页](index.html)：下载完整仓库后用浏览器打开，也可离线使用搜索、筛选与排序；外部论文和代码链接需要联网。
- [维护说明](CONTRIBUTING.md)：新增论文、修订信息和记录阅读笔记的方法。
- [更新记录](CHANGELOG.md)：汇总项目的主要变化。
- [图标来源说明](ICON_CREDITS.md)：当前透明背景橙色猫耳少女头像及历史图标来源。

## 电脑、平板与手机阅读

页面使用 Bootstrap 5.3.8 的响应式筛选抽屉，文献内容沿用现有表格与卡片布局。

- 宽屏（992px 起）：完整表格，直接选择筛选和排序条件。
- 平板及窄屏（768–991px）：文献卡片，信息分为三列；筛选收进抽屉。
- 手机（768px 以下）：单列文献卡片，信息按两列排列；小屏详情改为上下排版。
- 搜索和文献类型保持可见，筛选即时生效，页面显示已选条件；抽屉支持关闭按钮、遮罩和 Escape 键关闭。

Bootstrap 文件保存在 `vendor/bootstrap/`，响应式调整位于 `assets/responsive.css`。下载和部署时保留完整目录即可，无需构建命令。

## 内容与维护原则

- 保留论文原始链接和作者资源链接，便于回到原文核对。
- 区分正式发表版本与预印本，区分作者实现与第三方复现。
- 论文报告的结果与个人阅读判断分别记录；实验指标保留对应任务和条件。
- 会议等级、期刊分区和代码状态保留核验口径与来源，随信息变化修订。
- 新增或修改论文时同步维护 Markdown 汇总与 HTML 展示。当前两份文件尚未建立自动同步流程。

本次仓库整理沿用已有文献内容，没有重新核验全部论文及评级信息。具体来源和说明见汇总文件与展示页。
