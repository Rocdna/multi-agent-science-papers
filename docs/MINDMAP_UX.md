# Xmind 功能模式与文献画布设计

核对日期：2026-10-21；2026-11-03 调整为默认只读的文件展示。用户分享链接在无登录浏览器中跳转登录页，未操作其私有编辑界面。下面区分官方功能说明、截图观察与本项目设计，避免将桌面版／新版功能混称为分享页实际表现。

## 参考依据

- [官方：自由主题](https://xmind.com/zh-hans/user-guide/floating-topic)：可独立放置，支持空白双击创建；自由主题与一般主题可通过拖动转换，也可通过联系线连接。
- [官方：主题](https://xmind.cn/user-guide/topic-editing-new)：主题具有层级，提供工具栏、直接编辑和快捷键等入口。不同版本快捷键有差异，本项目保留 Tab 浏览器导航，子主题沿用 Ctrl / ⌘ + Enter。
- [官方：本地图片](https://xmind.com/zh-hans/user-guide/pic-new)：支持将图片插入主题。
- [官方：浮动工具栏](https://xmind.com/zh-hans/user-guide/floating-toolbar)：按选择提供相关操作；编辑文字时提供对应格式工具。
- [官方：联系](https://xmind.com/user-guide/relationship-new)、[外框](https://xmind.com/user-guide/boundary-new)：语义联系与视觉分组是独立能力，不能把一条任意连线当作父子层级。
- 用户截图：顶部工具以小图标和分隔组织，图文内容占据主要区域。图标精确含义不能仅凭截图确认。

## 借鉴的交互模式

| 模式 | 对阅读／整理的作用 | 本项目落地 |
|---|---|---|
| 画布作为工作区 | 内容占据视野，可自由移动和缩放 | 桌面上方两行共 100 px，其余交给画布；手机共 96 px；左下角缩放、适合窗口、定位根主题 |
| 结构化主题与自由素材并存 | 先收集，再决定归属 | 粘贴文字／图片、空白双击、拖入图片文件生成自由元素；不会因为此前选中主题就自动塞进该主题 |
| 直接操作 | 减少表单往返 | 文字双击编辑，元素拖动，图片等比调宽度；主题层级继续使用库的拖动布局 |
| 按对象显示工具 | 界面简洁且能知道当前可做什么 | 图标按钮按选择启用；属性与定位面板默认收起；快捷键、备份和发布说明放在帮助中 |
| 明确接入结构 | 区分自由位置与层级关系 | 拖到主题上高亮后松开；或“接入导图”再点击目标；接入变更真实父子关系 |
| 统一撤销和持久化 | 素材、层级和图片不会各存一套 | 单一文档历史与 IndexedDB 草稿；第 2 版 JSON 保存层级、图片数据和自由坐标 |

## 范围与实现取舍

2026-11-03 起公开页优先打通“打开／拖入 .xmind 或 JSON → 画布阅读”。XMind 读取文字层级、链接和内嵌图片，上传内容只在当前浏览中显示；编辑入口隐藏，原有编辑代码保留在 `?edit=1` 供内部维护。

编辑模式此前已打通“收集素材 → 自由摆放 → 接入主题 → 撤销／保存”。自由元素是单个图文节点，末级主题可以移回画布；整棵自由主题子树、任意联系线、概要、外框、区域分组暂不接入，也不放置无效图标冒充已支持。

继续使用原生 JavaScript 和本地 Mind Elixir 5.15.1 处理树布局。在同一变换坐标系中加入自由元素，平移不局限在主树边界内；统一历史让接入操作可以一步撤销。这个集成层承担本项目特有的自由素材与静态发布，不重写树布局引擎。

保留纯静态约束：网页编辑仅改变当前浏览器草稿；导出包含图片的文档后随仓库发布，公开版不读取访客草稿。没有账号服务器、云端同步或多人协作。当前 34 篇文献未自动配图，不把“支持图片”描述成“已导入论文图片”。
